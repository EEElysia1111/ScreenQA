# 本地知识库

## 导入

ScreenQA 设置页 → “导入知识库 .txt” → 选择一个或多个 `.txt`。

文件会复制到：

```text
Android/data/com.dsh.screenqa/files/kb/
```

也可以在该目录放 `.txt` / `.md`，重新打开设置页即可加载。

## 题库格式

一行一题，支持以下分隔符：

```text
题目|答案
题目<Tab>答案
题目｜答案
题目=>答案
题目->答案
题目 答案：答案
```

也支持两行格式：

```text
Q: 题目
A: 答案
```

要求题目至少 5 个字，答案非空。

## 匹配规则

- 去掉空白和标点后，按中文二元组计算 Jaccard 相似度。
- 相似度 ≥ 0.72 视为命中，直接返回题库答案。
- 命中后不调用 DeepSeek，胶囊显示“（来自本地题库）”。

题目要尽量完整；只写“第 5 题”这种无法匹配。

## 普通资料（RAG）

不是题库格式的内容会：

1. 按约 500 字切段，重叠 80 字。
2. 识别题目后，用题目二元组给每段打分。
3. 取最相关的 4 段，最多约 2500 字，拼进提示词。

适合课件、笔记、教材原文。

## 隐私

- 文件只存在手机本地。
- 只有检索命中的片段会随题目发送给 DeepSeek API。
- 卸载应用会删除这些文件。

## 建议

- 使用 UTF-8 编码。
- 按课程分文件。
- 题库答案要准确；命中后不会再让模型核对。
- 不要导入无权公开的题库或教材内容。
