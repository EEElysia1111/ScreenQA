# 安装与配置

## 1. 安装 APK

从 Releases 下载 `ScreenQA-*.apk`，或自行构建：

```bash
./gradlew :app:assembleRelease
```

如果系统提示“禁止安装未知应用”，在浏览器/文件管理器的应用信息里允许安装。

## 2. 首次配置

打开 ScreenQA，填写：

| 项目 | 默认值 | 说明 |
| --- | --- | --- |
| API Key | 空 | 在 DeepSeek 开放平台创建 |
| 选择题模型 | `deepseek-chat` | 快 |
| 填空/简答模型 | `deepseek-reasoner` | 慢，推理更强 |
| API 地址 | `https://api.deepseek.com` | 兼容 OpenAI 格式的地址也可以 |

点“保存”，再点“测试 DeepSeek 连接”确认可用。

## 3. 授予权限

1. **悬浮窗**：设置页 → “授予悬浮窗权限” → 允许。
2. **无障碍**：设置页 → “打开无障碍设置” → 已下载的服务 → ScreenQA → 开启。
3. **电池**：应用信息 → 省电策略 → 无限制。

Android 11 以下不支持 `takeScreenshot()`，无法静默截屏。

## 4. 小米 / HyperOS 额外设置

- 允许自启动。
- 电池策略设为“无限制”。
- 最近任务里给 TapTap 上锁，避免一键清理。
- 如果无障碍开关打开后自动弹回：先打开一次 ScreenQA，再进无障碍开启。

## 5. 双击背面（可选）

需要配套的 TapTap 补丁：

1. 卸载官方 TapTap（包名相同、签名不同，不能覆盖安装）。
2. 按 [TapTap-ScreenQA-Patch](https://github.com/EEElysia1111/TapTap-ScreenQA-Patch) 的说明构建并安装。
3. 打开 TapTap → 设置 → 双击动作 → 启动应用 → ScreenQA。
4. 确认 TapTap 的无障碍、悬浮窗、电池无限制都已开启。

不使用 TapTap 时，可以在控制中心添加“ScreenQA 识题”快捷开关，或直接点应用图标。

## 6. 本地知识库

设置页 → “导入知识库 .txt” → 选择文件。状态栏会显示 `X 题 / Y 段`。

题库格式见 [KNOWLEDGE_BASE.md](KNOWLEDGE_BASE.md)。

## 7. 验证

1. 打开一道选择题。
2. 双击背面，或点快捷开关。
3. 顶部胶囊应先显示“识别中…”/“DeepSeek 解题中…”，然后显示答案。
4. 点胶囊展开解析。

## 常见问题

### 双击没反应

- 看 TapTap 的常驻通知是否还在；不在就打开一次 TapTap。
- 检查 TapTap 前台服务、无障碍、悬浮窗、电池无限制。
- 用快捷开关对照，判断是触发问题还是截屏问题。

### 显示“信息不足”

- 确认题目完整显示在屏幕内，键盘/弹窗没有遮挡。
- 复盘页可能把“正确答案/教师批阅”一起读进去，建议在作答页使用。
- 点开胶囊查看完整内容，必要时提 Issue 并附题目截图（注意打码）。

### 总显示上一题

- 切题后停 0.5 秒再双击。
- 代码已加 450ms 稳定延迟和“只允许最新请求更新”的保护；如果仍复现，请附机型、ROM、题目页截图。

### 填空/简答很慢

- 使用的是 `deepseek-reasoner`，通常 10–30 秒。
- 想快可以把“填空/简答模型”改成 `deepseek-chat`，但正确率可能下降。
